# Quiet Reps

A phone PWA for a quiet, rep-based home training plan: 178 cm, 79 → 70 kg by 2027-02-28,
5 days a week (Mon, Tue, Thu, Fri, Sat), 15–20 minutes, full body, no jumping.
No build step and no dependencies. All data stays in the phone's `localStorage`.

## Blueprint

| Agent | Output in the code |
|---|---|
| Research | `data.js` `EXERCISES`: quiet, non-jumping movements, each with a rep range, 3 form cues and a harder variant |
| Trainer | `data.js` `DAYS` / `SCHEDULE` / `PHASES`; `engine.js` `buildSession` (supersets, rests, deload, 45 s rest phase) and `applySession` (double progression) |
| Optimization | `app.js`: one-tap rep logging, auto-starting rest timer, quiet feedback, weight trend, weekly calorie check |

### Weekly plan
- **Mon / Thu, Day A:** goblet squat + push-up, one-arm row + single-leg glute bridge, finisher (walk-out burpee + dead bug)
- **Tue / Fri, Day B:** single-leg Romanian deadlift + overhead press, reverse lunge + reverse fly, finisher (chair dip + calf raise)
- **Sat, Day C:** 4-round circuit (Bulgarian split squat, push-up, row, Romanian deadlift, reverse crunch)
- **Max test:** max push-ups and squats; suggested in week 1 and week 17

Supersets: A → 10 s switch → B → 60 s rest, 3 rounds. Circuit: 90 s rest after each round.

| Weeks | Phase | Effect in the app |
|---|---|---|
| 1–4 | Foundation | Start at the bottom of each rep range |
| 5–8 | Build | Normal progression |
| 9 | Deload | Every exercise drops to 2 sets |
| 10–16 | Push | Superset and finisher rest drops to 45 s |
| 17 | Test | Home suggests the max test |

### Progression
- **Target reps:** the target rises by 1 (up to the top of the range) after a session where every set reached it. One-side exercises count the weaker side. Skipped sets block progress.
- **Level-up suggestion:** hitting the top of the range in every set for 2 sessions in a row suggests the next step, which you can accept or decline:
  1. Slower tempo (4 s down + 1 s pause)
  2. An extra set
  3. The harder variant (e.g. push-up → decline → archer)

### Rest timer
- Starts automatically after **Done**.
- Counts down from a stored end time, so it stays correct through screen locks and reloads. An in-progress workout resumes where it was left.
- Buttons: −15 s, +15 s, Skip. A preview of the next exercise shows during rest.
- **Quiet by default:** vibration at 3-2-1 and a screen flash. Sound is opt-in in Settings.
- Keeps the screen awake during a workout.

### Weight and food
- **Weigh-in:** daily, with a stepper. The chart shows daily dots, a 7-day average, and a dashed target line from 79 to 70 kg.
- **Weekly check (Sat/Sun):** compares 7-day averages two weeks apart. Under 0.4 kg/week, it suggests −150 kcal. Over 0.9 kg/week, it suggests +150 kcal. It never goes below 1,600 kcal.
- **Food:** daily yes/no ticks for calories (start 1,900 kcal) and protein (140 g).

## Run and test
```
npm test                 # engine tests
node tools/serve.mjs     # http://localhost:5173/
```

## Updating
After changing any file, bump `VERSION` in `sw.js`. Otherwise installed phones keep the old cached copy.
If you add a file, also add it to `SHELL` in `sw.js`.

## Installing on the phone
A PWA must be served over HTTPS to install and work offline. `http://<LAN IP>` is not enough.
Options:
- **Static hosting:** GitHub Pages, Netlify, Cloudflare Pages, or similar. Open the URL on the phone, then use "Add to Home screen" (Android Chrome) or Share → "Add to Home Screen" (iOS Safari).
- **Android over USB:** `adb reverse tcp:5173 tcp:5173`, then open `http://localhost:5173` on the phone.

Data lives only in that browser on that phone. Use Settings → Export backup now and then.
